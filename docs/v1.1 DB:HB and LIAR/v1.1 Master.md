# plan.md — Build a Game Empire (Roblox)

> Title: **Build a Game Empire**
> Built in Roblox Studio via the **Roblox Studio MCP Server** with Claude as the building agent.

---

## 0. Glossary

| Term | Meaning |
|---|---|
| **GOTY** | **Game of the Year** — annual award for the best game released that in-game year (player or rival). |
| **COTY** | **Company of the Year** — annual award for the best-performing company (player or rival). |
| **RP** | Research Points — currency generated by staff/labs, spent on research. |
| **Tech Tree** | Node graph of technologies unlocked over time via research (modeled on *Build a Phone Empire*). |
| **Trend** | A genre/theme/platform/feature that is currently popular; changes yearly, shifts hard per decade. |
| **Plot** | The player's company lot in the world; buildings are placed here. |
| **Tick** | One simulation step on the server (= 1 in-game day). |
| **Speed** | Time multiplier: 1x / 2x / 4x / 10x. |
| **Rival** | AI-controlled competing company. |
| **IP** | Intellectual property — a game franchise the player owns (sequels inherit fans). |
| **MCP** | Model Context Protocol — the bridge that lets Claude create/edit Instances and scripts in Studio. |
| **Agent** | The AI (Claude) building this game through MCP. |

## 1. Game Identity

- **Roblox Genre:** Simulator
- **Roblox Subgenre:** Tycoon
- **Pitch:** Start a one-person game studio in a garage in **1970**. Research new technology, chase trends, invent marketing and sales methods, hire staff, build a campus, design consoles, run factories, and beat rival companies to win **GOTY (Game of the Year)** and **COTY (Company of the Year)** — growing into a Rockstar-level giant shipping your own "GTA VI"-scale blockbuster.
- **Reference game (UX + progression):** *Build a Phone Empire* — https://www.roblox.com/games/101914705206759/Build-a-Phone-Empire
  - Copy: 3rd-person fixed-camera tycoon view, **no player movement**, click-the-world interaction, panel-based UI, skill-tree research where new tech must be researched as time progresses.
- **Session target:** 20–40 min sessions; full 1970→2030 campaign ≈ 8–15 hours at mixed speeds.
- **Audience:** 10+; readable UI, no realistic violence (games-within-the-game are shown abstractly).

## 2. Agent Autonomy Rules

The agent **may decide to add** features, content, and polish not listed here, **if**:

1. It fits the core loop (research → develop → market → sell → grow).
2. It does not break existing save data (bump `SaveVersion` + write a migration).
3. It is data-driven (added to a ModuleScript table, not hard-coded).
4. It is logged in `CHANGELOG.md` under "Agent additions" with a one-line rationale.

Encouraged agent additions (examples, not required): seasonal events, sequels/IP fan system, crunch/morale events, piracy events, employee traits, achievements, news ticker headlines, acquisitions of rivals, game remasters, indie publishing deals.

The agent **must ask the user** before: adding monetization (Robux), adding real-world brand names, changing the start year/speed tiers, or removing any listed system.

## 3. UX / Presentation (copy *Build a Phone Empire*)

### 3.1 Camera & Player
- Character spawns but is **anchored and hidden** (`Transparency = 1`, `WalkSpeed = 0`, `JumpPower = 0`), or not loaded at all (`Players.CharacterAutoLoads = false`).
- `Camera.CameraType = Scriptable`, fixed **isometric 3rd-person angle** (~45° pitch) over the player's plot.
- **Pan:** drag (mouse/touch) clamped to plot bounds. **Zoom:** scroll/pinch between min/max. **Rotate:** optional 90° snaps (Q/E buttons).
- Camera tweens to a building when it's clicked.

### 3.2 Interaction
- Click/tap a building in the world → opens its panel (e.g., Research Lab → Tech Tree).
- Hover highlight (`Highlight` instance) + floating name label (`BillboardGui`).
- Empty grid slots show a "+" BillboardGui → opens Build menu filtered to that slot size.

### 3.3 HUD Layout
- **Top bar:** Cash, RP, Fans, Reputation (★), Date (Month YYYY), Speed buttons `⏸ 1x 2x 4x 10x`.
- **Bottom dock (tabs):** Research · Develop · Staff · Build · Marketing · Sales · Factory · Consoles · World · Settings.
- **Right side:** Active projects (dev progress bars, research queue, factory output).
- **Left side:** Toast notifications (events, releases, awards); click to open details.
- **Center modal:** Release review screen, GOTY/COTY ceremony, decade-transition cinematic.
- **News ticker** (bottom edge, optional): headlines about rivals, trends, world events.

### 3.4 Visual Plot Growth
| Stage | Unlock | Look |
|---|---|---|
| Garage | Start | 1 small building, 1 desk |
| Small Office | $50k + 3 staff | Single-floor office |
| Studio | 1st hit game | Multi-room, parking lot |
| Campus | COTY nominee | Multiple buildings, landscaping |
| Megacorp | 1st console + factory | HQ tower, factories, logo sign |

Buildings snap to a grid (e.g., 4×4 stud cells, slots of 1×1, 2×2, 3×3).

### 3.5 UI Style
- Clean, rounded panels (`UICorner`), consistent palette per era (70s browns/oranges → 80s neon → 90s teal/purple → 2000s chrome → modern flat).
- Every panel: title, close button, tooltip on every stat.
- Mobile-first scaling (`UIScale`, `UIAspectRatioConstraint`); min tap target 44px.

## 4. Time System

- **Start:** January 1, 1970. **Soft end:** 2030 (sandbox continues afterward).
- **Base rate (1x):** 1 in-game day = 0.5 real seconds → 1 year ≈ 3 min at 1x. (Tunable in `Config`.)
- **Speeds:** `0x (pause) / 1x / 2x / 4x / 10x`. 10x unlocks after first released game (agent may adjust).
- **Auto-pause** on: game release review, GOTY/COTY ceremony, decade transition, bankruptcy warning.
- **Events fired (server `BindableEvent` bus):** `DayPassed`, `WeekPassed`, `MonthPassed`, `QuarterPassed`, `YearPassed`, `DecadePassed`.
- **Offline progress:** none by default (agent may add capped offline earnings, max 2 in-game months).
- Each player's clock runs independently on their own plot.

## 5. Systems (v1)

### 5.1 Technology Research (Tech Tree)
- Node graph UI (pannable, zoomable), styled like *Build a Phone Empire*.
- Each node: `id, name, era, minYear, rpCost, researchDays, prereqs[], unlocks[]`.
- Nodes are **locked before `minYear`** (shown greyed "Available in 1983").
- Research queue (1 slot, +1 per Research Lab upgrade).
- **Branches:**
  - **Graphics:** Text → ASCII → 2D Sprites → Color Palettes → Scrolling → Pseudo-3D → 3D Polygons → Textured 3D → Shaders → HD → Photoreal → Ray Tracing
  - **Audio:** Beeper → Chiptune → FM Synth → CD Audio → Surround → Orchestral → Spatial Audio
  - **Media/Storage:** Cartridge → Floppy → CD-ROM → DVD → Blu-ray → Digital-only
  - **Gameplay:** Save Games → Open Levels → Physics → AI Companions → Open World → Procedural Gen → Live Service
  - **Network:** Local 2-Player → LAN → Online Multiplayer → Matchmaking → MMO → Cross-play → Cloud Gaming
  - **Engine:** Custom Code → Reusable Engine → Level Editor → Licensed Engine → In-house AAA Engine
  - **Hardware (for consoles):** CPU tiers, GPU tiers, RAM, controllers (D-pad → analog → rumble → motion → haptics), handheld, VR
- Unlocking tech enables new features in Game Dev and parts in Console Dev.

### 5.2 Trend Research
- Each year the server rolls **trend weights** for genres, themes, platforms, and features.
- **Yearly shift:** small (±10–25% weight).
- **Decade shift:** dramatic (top trends reshuffled; some genres crash, new ones emerge).
- Decade flavor (example):
  - 1970s: Arcade, Pong-style, Text Adventure
  - 1980s: Platformer, Shoot 'em up, RPG, Home console
  - 1990s: 3D, Fighting, FPS, RTS, CD multimedia
  - 2000s: Open World, Online, MMO, Sports, Casual
  - 2010s: Mobile, Battle Royale, Indie, Live Service, Esports
  - 2020s: VR, Cross-play, Remasters, Cozy, AI-driven
- Trends are **hidden** by default. Trend Research reveals:
  - Tier 1: current year's top 3.
  - Tier 2: next year forecast.
  - Tier 3: next 3 years + decade preview.
- Matching trends at release = big review/sales multiplier.

### 5.3 Marketing Research
Researchable channels, unlocked by era. Each: `cost, reach, hypeGain, demographicFit, unlockYear`.
- Word of Mouth (free, start)
- Newspaper Ads → Magazine Ads → Gaming Magazine Previews
- Radio → TV Commercials → Prime-time TV Spots
- Arcade Demo Machines → In-store Kiosks → Demo Discs
- Trade Shows → Industry Expo (E3-style) → Own Showcase Event
- Fan Clubs / Newsletters → Website → Forums
- Trailers → Viral Video → Livestream Premieres
- Social Media → Influencers → Streamers / Content Creators
- Billboards → Celebrity Partnerships → Movie Tie-ins
- ARGs (Alternate Reality Games) → Leaks (risky, random outcome)
- Esports Sponsorships

Marketing builds **Hype** before release; Hype decays over time if release is delayed.

### 5.4 Sales Method Research
- Mail Order → Retail Boxes → Big-box Retail Deals
- Pre-orders → Pre-order Bonuses
- Collector's / Limited Editions
- Console Bundles (requires own console or partner deal)
- **Special Promotions**: themed limited-edition hardware (e.g., a branded controller for a big release)
- **Gift Cards** for digital stores (parody brands)
- Digital Storefront → Own Digital Store
- Seasonal Sales / Discounts
- DLC → Expansion Packs → Season Pass
- Subscription Service
- Microtransactions (reputation risk if overused)
- Merchandise (requires Factory)

### 5.5 Staff
- **Roles:** Programmer, Designer, Artist, Audio, Writer, Producer, Marketer, Hardware Engineer, Researcher, Factory Worker.
- **Stats:** Skill (1–100 per role), Speed, Creativity, Morale, Salary, Experience/Level, Traits (agent may add).
- **Hiring:** candidate pool refreshes monthly; better candidates appear with higher reputation. Recruitment tiers (Ads → Agency → Headhunter).
- **Management:** train (cost + time), promote (raise salary), fire, assign to project/building.
- **Morale:** affected by crunch, salary vs market, office quality, wins/awards. Low morale → slower work, quitting, rivals poaching.
- Headcount limited by building capacity.

### 5.6 Buildings
| Building | Function | Upgrades |
|---|---|---|
| Garage (start) | 1–2 staff | — |
| Office | Staff capacity | Floors I–V |
| Research Lab | RP generation, research slots | Tiers I–IV |
| Marketing Dept | Unlocks campaigns, reduces cost | I–III |
| Sound Studio | Audio quality bonus | I–III |
| Motion Capture Stage | Late-era quality bonus | I–II |
| Hardware Lab | Console Dev | I–III |
| Training Center | Faster staff training | I–II |
| Factory | Self-production | See 5.9 |
| Server Farm | Online/live-service games | I–IV |
| HQ | Prestige, global bonuses | I–V |
| Decor (parks, statues, award cabinet) | Morale bonus, GOTY trophies displayed | — |

Each building: cost, upkeep/month, footprint, capacity, bonuses, unlock condition.

### 5.7 Game Development
**Flow:** New Game → Concept → Production → Polish → Release → Sales lifecycle.
1. **Concept:** name, genre, theme, platform(s), target audience, size (Small / Medium / Large / AAA / Mega-AAA), engine.
2. **Features:** pick unlocked tech features (limited by engine + size).
3. **Focus sliders (3 phases):** Gameplay, Graphics, Story, Audio, World, AI, Multiplayer, Polish.
4. **Staff assignment:** team size affects speed and quality.
5. **Production:** progress bars, random events (bugs, scope creep, leaks, breakthroughs); option to **crunch** (faster, morale hit) or **delay** (better quality, hype decay).
6. **Release:** reviews from 4–6 parody outlets (0–10). Score formula:
   `quality(staff, sliders vs genre ideals, tech) × trendFit × innovationBonus − bugs`
7. **Sales:** curve with launch spike → decay; boosted by hype, reviews, fans, platform install base, sales methods.
- **IP / Sequels:** franchises gain fans; sequels inherit fanbase, but repeat-fatigue lowers score if unchanged.
- **Mega-AAA** unlocks late: the "GTA VI moment" — giant budget, multi-year dev, world-shaking launch.

### 5.8 Console Development (v1)
- Requires Hardware Lab + Hardware Engineers.
- **Design:** choose CPU, GPU, RAM, media, controller, form factor (home / handheld / hybrid), online features — all from researched tech.
- **Specs → Power score**; **cost → production cost**; set retail price.
- **Dev time** months–years; launch date matters (holiday bonus).
- **Market:** install base grows monthly; third-party games (rivals) release on it if it's popular → licensing royalties.
- **Lifecycle:** console generations; old consoles decline when successors launch.
- Without a factory: outsource production (higher unit cost).

### 5.9 Factories (Self-Production)
- Produce: cartridges, discs, retail boxes, consoles, controllers, special-edition hardware, merchandise.
- **Stats:** throughput/month, unit cost, defect rate, upkeep, workers.
- Upgrades: Assembly Line → Automation → Robotics.
- Self-production lowers unit cost vs outsourcing; shortages delay shipments (lost sales).
- Inventory management panel (agent may simplify to auto-produce with a toggle).

## 6. World Systems

### 6.1 Rival Companies
- 6–8 AI rivals with **parody names** (no real brands). Example archetypes:
  - Arcade pioneer (strong 70s, fades)
  - Console giant (hardware focus)
  - Plumber-mascot style family company (quality, IP-heavy)
  - Open-world blockbuster studio (rare, huge releases)
  - Sports annualizer
  - PC strategy studio
  - Mobile/live-service upstart (appears 2000s+)
  - Indie darling (random breakout hits)
- **Behaviors:** release games on schedule, follow trends, launch consoles, set prices, run marketing, poach staff, can go bankrupt or be **acquired** (late game).
- Rival stats tracked: revenue, fans, reputation, GOTY wins, market share.
- Rivals appear/disappear across decades.

### 6.2 GOTY — Game of the Year
- Ceremony every **December** (auto-pause).
- Nominees: top 5 games released that year by review score + sales weight (player + rivals).
- Categories (agent may add more): Overall GOTY, Best Graphics, Best Audio, Best Story, Best Multiplayer, Best Indie.
- **Rewards:** fan surge, reputation, sales spike for winner, trophy model placed in Award Cabinet on plot.

### 6.3 COTY — Company of the Year
- Announced at same ceremony after GOTY.
- **Score:** revenue growth + average review + innovation (first to ship new tech) + fan growth + awards won.
- **Rewards:** reputation, better hiring pool, prestige currency (optional), HQ statue.

### 6.4 World Leaderboards (Roblox-wide)
- `OrderedDataStore` leaderboards: Net Worth, Total GOTY Wins, Total COTY Wins, Highest Review Score.
- Physical leaderboard board in the lobby/plot view.

## 7. Economy & Balance

- **Start:** $10,000, 1 founder (the player's avatar as CEO, stat-free).
- **Income:** game sales, console sales, royalties, DLC/subscriptions, merch, licensing.
- **Expenses:** salaries, building upkeep, research, marketing, factory operations, server costs.
- **Bankruptcy:** cash < 0 for 3 months → warning; 6 months → restart prompt (keep cosmetics).
- **Inflation:** costs and prices scale by era (`eraMultiplier` table).
- All numbers live in `Config` + data modules for quick tuning.

### 8.2 Rules
- **Server-authoritative:** all cash, RP, research, hiring, building placement validated on server.
- Client sends **intents** only (e.g., `RequestResearch(nodeId)`); server validates and replies.
- Rate-limit remotes per player.
- **Replication:** server pushes state deltas monthly (or on change) via a single `StateUpdate` remote; client keeps a local mirror for UI.
- At 10x, batch daily ticks; never fire per-day remotes.
- **Save data:** single table per player with `SaveVersion`; autosave every 60s, on leave, and on `BindToClose`; session locking to prevent dupes.
