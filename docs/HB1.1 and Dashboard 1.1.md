# Headbands 1.1: Habit to Wear

When accessed on a computer, the Headbands UI should scale horizontally rather than vertically. At the start of the site, consider asking whether the user is on mobile or desktop so the layout can adapt appropriately.

For Jeopardy 1.1 and Headbands 1.1, identify the changes that would benefit both apps right now.

## Music

For both Jeopardy and Headbands, the music files will replace the public directory under the root `public` folder. Place the audio files in `~/public/music`. Use these tracks as very subtle ambient sounds when the user hovers over the games. Include a speaker toggle so users can mute or unmute the audio as needed.
